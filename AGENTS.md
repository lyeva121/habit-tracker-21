# AGENTS.md — общая информация о проекте

## Что это

Личный трекер привычек «21» для iPhone. Веб-приложение (PWA): разрабатывается на Windows, пользователь открывает его в Safari и добавляет на домашний экран. Привычка считается выработанной после 21 выполнения подряд по своему расписанию; один пропуск запланированного дня обнуляет серию. Полное ТЗ — см. `first-plan.md`.

## Стек

- **Vite + React + TypeScript** — фронтенд без бэкенда
- **localStorage** — всё хранение данных (прогресс живёт на телефоне пользователя)
- **Vitest** — автотесты логики (обязательны для задач календаря и серий)
- **GitHub Pages** — хостинг (HTTPS нужен для PWA)

## Команды

```
npm run dev            # дев-сервер (добавить -- --host для доступа с iPhone по Wi-Fi)
npm run dev -- --host  # дев-сервер, доступный с телефона: http://<IP>:5173
npm test               # прогон Vitest
npm run build          # прод-сборка
```

После изменений в логике всегда запускать `npm test`.

## Структура (целевая)

```
src/
  logic/        # чистые функции: расписание, серии, план дня — без React и DOM
  storage/      # загрузка/сохранение localStorage, экспорт/импорт JSON
  components/   # переиспользуемые элементы (кнопка, круг прогресса, календарь)
  screens/      # экраны: Today, Yesterday, Habits, HabitForm, Journal, History
  App.tsx       # оболочка + нижняя вкладка
```

## Правила предметной области (не нарушать)

1. **Даты** — строки `YYYY-MM-DD` в локальном времени устройства. Не UTC, не объект Date в хранилище. Граница дня — местная полночь.
2. **Расписание**: привычка запланирована в день D, если день недели D входит в её дни недели и D ≥ даты начала отсчёта. До даты старта дней нет.
3. **Серия**: +1 за каждый выполненный запланированный день. Считается по логу отметок от даты старта (единственный источник правды — лог, счётчики не храним).
4. **Закрытие дня**: запланированный день D провален в конце дня D+1, если отметки за D нет. Отметить задним числом можно только вчера — окно ровно один день.
5. **Пропуск** → серия 0 + событие «сорванная серия» (дата, счёт, на котором оборвалось, id привычки).
6. **21 подряд** → привычка получает статус `achieved`, выпадает из плана дня, отображается в секции «Достигнутые».
7. **Дневник изменений**: у привычки включается флагом; при отметке вводится число; график — X: номер выполнения 1…21, Y: значение, ось Y от 0 до **2×первой записи** (первая точка ровно посередине).
8. При запуске приложения сначала «дозакрываются» пропущенные дни (пользователь мог не открывать приложение недели), затем рисуется «Сегодня».

## Экраны

Сегодня (по умолчанию при открытии), Вчера (открывается по красной плашке «Вчера», не вкладка), Мои привычки (+форма), Дневник, История. Навигация — нижняя панель.

## Дизайн

Светлая спокойная тема. Мягкий зелёный — основной акцент (выполнено, прогресс); неглубокий синий — второстепенный; фон почти белый; много воздуха. Нажимаемые элементы ≥48px, шрифт в полях ввода ≥16px (иначе Safari зумит). Константы цветов/отступов — в одном файле, хардкод значений в компонентах не разводим.

## Соглашения по коду

- Комментарии в коде не пишем (кроме случаев, когда просит пользователь).
- Текст интерфейса — русский. Имена в коде — английские.
- Вся логика дат/серий — чистые функции в `src/logic/` с тестами; в компонентах только вызовы.
- Данные для localStorage сериализуем целиком одним ключом на сущность; при изменении схемы — миграция со старой версии.

## Чего в проекте нет и не будет

Push-уведомления, e-mail, регистрация и аккаунты, друзья/лента/соревнования, серверная часть и синхронизация между устройствами. Не добавлять библиотеки для этого «на будущее».

## Пользователь проекта

Новичок в программировании, работает с ИИ-агентом. Объяснения — простым языком, без шагов «очевидных» для программиста; команды для терминала давать готовыми к копированию.
